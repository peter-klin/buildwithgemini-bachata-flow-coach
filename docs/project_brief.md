# My agent: BachataFlow Coach

One-liner: A conversational dance instructor agent that teaches dancers new Bachata combinations, footwork, and partnerwork combos with a catalog of curated social dance moves inspired by trending video routines.

Tool coverage:
- Memory: Remembers the dancer's skill level (Beginner / Intermediate / Sensual / Dominican), preferred role (Lead or Follow), favorite styling preferences, and moves already mastered in past practice sessions.
- Tools: Search dance move catalog, recommend combo progressions based on mastered moves, filter moves by style/difficulty, and fetch structured 8-count breakdown steps.
- Catalog/UI: Catalog of Bachata moves (e.g. Madrid Step, Shadow Position Walk, Sensual Body Wave, Syncopated Footwork, Hammerlock Exit) rendered as rich A2UI cards displaying difficulty, role cues, and step-by-step 8-count counts.
- Image gen: Generates instructional visual diagrams and stylized dance posture / partner position illustrations (e.g., hand connection grips, body wave posture cues).
- Sandbox: Computes musicality counts, BPM tempo-to-count breakdowns, and practice session interval timing.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Video routine links / YouTube references, audio rhythm metronome, Cloud Trace
